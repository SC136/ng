Short links

Every short link on this site. Each one works at ng.foo.ng/<slug> and redirects to its target.

    How they work

    Open ng.foo.ng/<slug> and you are sent to the target. Case and a trailing slash don't matter.

    Extra path segments pass through to the target: ng.foo.ng/gh/ng goes to github.com/SC136/ng. A query string is added to the target too.
