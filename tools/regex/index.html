Match details

Matches and their groups appear here.

Use $1 for a numbered group, $<name> for a named one, $& for the whole match and $$ for a dollar sign. Leave it empty to remove the matches. Without the g flag only the first match is replaced.

Syntax cheat sheet

Characters

.
Any character except line breaks (all with s)
\d \w \s
Digit, word character, whitespace
\D \W \S
Not a digit, word character, whitespace
[abc]
Any of a, b or c
[^a-z]
Anything but a to z
\p{L}
Any letter (needs u or v)
\t \n é
Tab, newline, code unit

Anchors

^ $
Start and end of text (of each line with m)
\b \B
Word boundary, not a word boundary

Quantifiers

* + ?
0 or more, 1 or more, 0 or 1
{3} {2,} {2,5}
Exactly 3, 2 or more, 2 to 5
*? +?
Lazy: as few as possible

Groups

(abc)
Capture group
(?<name>abc)
Named group
(?:abc)
Group without capturing
\1 \k<name>
Back-reference
a|b
a or b

Lookaround

(?=x) (?!x)
Followed by x, not followed by x
(?<=x) (?<!x)
Preceded by x, not preceded by x
